Система управления группировками спутников и выполнения космических миссий. Проект разработан в рамках курса по системному дизайну.

## Ключевой пользовательский сценарий для нагрузочного тестирования

Нагрузочный тест воспроизводит работу оператора космического центра, выполняющего полный цикл управления спутниковой группировкой.

| Шаг | Действие пользователя | HTTP метод | Эндпоинт |
|-----|-----------------------|------------|----------|
| 1 | Просмотр системной сводки | GET | /api/overview |
| 2 | Просмотр списка группировок | GET | /api/constellations |
| 3 | Просмотр списка спутников | GET | /api/satellites |
| 4 | Создание новой группировки спутников | POST | /api/constellations |
| 5 | Добавление спутников в группировку | POST | /api/add-satellites |
| 6 | Запуск выполнения миссии | POST | /api/missions |
| 7 | Получение статистики по группировке | GET | /api/constellations/{name}/statistics |
| 8 | Активация спутников | POST | /api/constellations/{name}/activate |
| 9 | Деактивация спутников | POST | /api/constellations/{name}/deactivate |
| 10 | Удаление тестовой группировки | DELETE | /api/constellations/{id} |

### Распределение типов запросов

| Тип запроса | Количество | Доля от общего числа |
|-------------|-----------|----------------------|
| GET (чтение данных) | 4 | 40% |
| POST (создание и изменение) | 5 | 50% |
| DELETE (удаление) | 1 | 10% |

### Профиль нагрузки

Тест выполняется по этапам с нарастанием и удержанием нагрузки.

| Этап | Длительность | Количество пользователей |
|------|-------------|--------------------------|
| Разгон | 10 секунд | от 0 до 10 |
| Разгон | 20 секунд | от 10 до 50 |
| Удержание | 30 секунд | 50 |
| Разгон | 20 секунд | от 50 до 100 |
| Удержание | 30 секунд | 100 |
| Завершение | 10 секунд | от 100 до 0 |

Общая длительность теста составляет 120 секунд. Максимальная нагрузка достигает 100 одновременных пользователей.
## Инструкция по запуску проекта и тестов

### Запуск проекта

```bash
cd satellite_constellation
docker-compose up -d
```

### Запуск нагрузочных тестов

Дымовой тест выполняет однократную проверку всех эндпоинтов.

```bash
k6 run load-tests/smoke-test.js
```

Основной нагрузочный тест запускается с генерацией HTML-отчёта.

```bash
k6 run --summary-export=load-tests/results/summary.html load-tests/mission-scheduler-test.js
```

### Просмотр отчёта

```bash
start load-tests/results/summary.html
```
