# Система управления спутниковой группировкой

Проект, реализующий систему управления спутниковой группировкой.

## Описание проекта

Система моделирует управление спутниковой группировкой аэрокосмической компании, включая:
- Создание различных типов спутников (связи и дистанционного зондирования Земли)
- Управление их состоянием (активация/деактивация)
- Выполнение специализированных миссий
- Объединение спутников в группировки
- Централизованное управление группировками

## Требования к системе

### Функциональные требования
1. Создание и использование спутников через общий базовый класс
2. Реализация спутника ДЗЗ для съемки Земли
3. Реализация спутника связи для передачи данных
4. Объединение спутников в группировки
5. Тестирование всех функций в основном классе

### Технические требования
1. Использование принципов ООП (наследование, полиморфизм, инкапсуляция, абстракция)
2. Расширяемость системы для новых типов спутников
3. Демонстрация работы всех возможностей системы

### Сборка и запуск

```bash  
# Компиляция  
javac -d build src/main/java/org/example/*.java  
  
# Запуск  
java -cp build org.example.Main  
```
